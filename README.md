#### 🔎 Spotlight: html-to-markdown (Xberg.io)

Rust-based HTML → Markdown converter with WebAssembly bindings. My work was reviewed by the project maintainer and code owner, then landed through follow-up PRs with my commits and authorship preserved.

- **[#720](https://github.com/xberg-io/html-to-markdown/pull/720) — Preserve block separation in table cells** · fixes [#692](https://github.com/xberg-io/html-to-markdown/issues/692)<br>
  Block-level elements inside table cells no longer join the surrounding text. Added `<center>`, `<dialog>`, `<hgroup>` and `<search>` as block-level elements, with regression tests for the Tier 1 and Tier 2 converters and different table configurations. Integrated through [#733](https://github.com/xberg-io/html-to-markdown/pull/733).
- **[#721](https://github.com/xberg-io/html-to-markdown/pull/721) — Preserve WASM visitor handle ownership** · fixes [#517](https://github.com/xberg-io/html-to-markdown/issues/517)<br>
  Assigning a `WasmVisitorHandle` no longer consumes the JavaScript handle, so it can be reused. Updated the Alef-generated bindings and added regression tests for visitor reuse and `clearVisitor()`. Split into [#726](https://github.com/xberg-io/html-to-markdown/pull/726) (Alef upgrade and regenerated bindings) and [#727](https://github.com/xberg-io/html-to-markdown/pull/727) (tests and WASM coverage).
- **[#652](https://github.com/xberg-io/html-to-markdown/pull/652) — Preserve blockquotes in task items**<br>
  Initial fix and regression tests for a blockquote at the start of a task item being rendered on the checkbox line. The underlying bug was fixed on the integration branch by another PR; the maintainer kept my tests with me as commit author, and they reached `main` through [#581](https://github.com/xberg-io/html-to-markdown/pull/581).
- **[#701](https://github.com/xberg-io/html-to-markdown/pull/701) / [#703](https://github.com/xberg-io/html-to-markdown/pull/703) — Keep a `<br>` on its own line as a hard break**<br>
  Original fix for a `<br>` on its own source line becoming a paragraph break, plus regression tests for block elements, comments, whitespace, inline wrappers and newline styles. Carried forward into [#717](https://github.com/xberg-io/html-to-markdown/pull/717), where the maintainer extended it to the fast converter and more edge cases; merged with my authorship preserved.
